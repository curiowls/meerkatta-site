Mac BYOK & Coding Workflows

Use Claude Code or Codex CLI for Mac Dictation Cleanup

If you already pay for a coding-tool subscription on your Mac, turning rough speech into clear text doesn’t have to mean adding another monthly dictation bill or managing a separate polishing API key.

The short answer

Reuse your installed CLI for the cleanup step—keep transcription separate.

What MeerKatta does on Mac: In Settings → Providers & Keys, MeerKatta separates Transcribing (speech to raw words) from Polishing (cleaning up filler, self-corrections, and structure). On MeerKatta Lifetime ($33 launch / $49 regular)—and during the 7-day Mac trial—MeerKatta automatically detects installed Claude Code and Codex CLI binaries for the Polishing stage.

Built for text cleanup, not coding tasks: MeerKatta invokes each CLI from a temporary working directory for plain-text editing—disabling built-in tools and MCP servers on Claude Code, and running Codex CLI with read-only restrictions and session-file persistence off. Dictating a prompt gives you cleaned text at your cursor to review instead of kicking off a workspace task.

Honest boundaries: Detecting an installed binary is not the same as having an eligible, signed-in subscription. CLI cleanup still uses your provider’s cloud servers and shared plan usage limits, and CLI polishing is Mac-only.

Developers who dictate prompts, PR comments, Slack replies, or design notes often hit an odd friction: they already pay for Claude or ChatGPT every month for coding agents, yet most AI dictation apps ask for either a second monthly subscription or a freshly funded developer API key just to polish short bursts of speech. MeerKatta’s Mac pipeline splits transcription from polishing so you can plug the coding CLI you already use into the cleanup step.

Two separate jobs: speech recognition vs. AI cleanup

Your CLI receives text, not audio. Speech-to-text happens first using whichever Transcribing provider you select. MeerKatta then sends that transcript to Claude Code or Codex CLI together with relevant personalization and request context—such as your vocabulary, writing preferences (tone, style, or approved writing samples), the active app name, and prior text when applicable—so the cleaned draft fits where you’re working.

How to set up Claude Code or Codex CLI cleanup on Mac

Credentials stay with your CLI, never inside MeerKatta. MeerKatta does not ask you to paste OAuth tokens or sign into Anthropic or OpenAI inside the app. You sign in through the CLI itself, then verify the connection in MeerKatta.

  1. 01

    Install and verify sign-in in Terminal

    Make sure the CLI works on its own and check which account or billing method it reports before opening MeerKatta.

    Claude Code

    claude auth login
claude auth status

    Codex CLI (ChatGPT account)

    codex login
codex login status

    For Codex CLI, choose Sign in with ChatGPT rather than an OpenAI API key—MeerKatta’s Codex CLI route uses ChatGPT account access only.

  2. 02

    Open Settings → Providers & Keys in MeerKatta

    Installed Codex CLI and Claude Code binaries appear automatically under Polishing. If you just installed a CLI while MeerKatta was open, restart MeerKatta or click + Add provider to add it.

  3. 03

    Run Test, review the detected auth mode, then Save

    Click the Claude Code or Codex CLI tile to open its setup sheet. MeerKatta displays the authentication state it detected, then runs a real short polish test when you click Test. Once the test succeeds, click Save and hover the tile to make it your primary polishing provider.

  4. 04

    Pick your Transcribing provider above it

    Choose built-in offline Apple Speech or On-device Whisper if you want no API keys at all, or add a cloud transcription key (such as Groq, OpenRouter, or DeepInfra) for stronger raw recognition when you’re online.

Three practical Mac pairings

Because Transcribing and Polishing are independent, you can match your stack to what you already pay for—and switch transcription anytime without touching your cleanup setup.

Zero API keys

Local transcription + CLI cleanup

Pair Apple Speech or On-device Whisper with Claude Code or Codex CLI. Nothing else to sign up for—just keep in mind on-device speech recognition is less accurate than large cloud models on uncommon names or noisy rooms.

Best online accuracy

Cloud speech API + CLI cleanup

Use a cloud transcription key (such as Groq or OpenRouter) for sharper raw transcripts while letting your existing Claude Code or Codex CLI handle cleanup.

No network

Offline raw dictation

On an airplane or offline Wi-Fi, CLI cleanup can’t reach Anthropic or OpenAI—so MeerKatta falls back to raw text from Apple Speech or On-device Whisper, or you can turn polishing off temporarily.

Usage limits, billing caveats, and honest boundaries

  • Shared subscription quota, never “unlimited”: Non-interactive calls via claude -p or codex exec count toward your existing provider plan’s usage allowance (such as rolling session/weekly limits on Claude or shared token allowances on ChatGPT/Codex) under that provider’s current terms. Short dictation cleanups are small compared to multi-step coding sessions, but they are still metered by your provider.
  • Check environment variables on Claude Code: If ANTHROPIC_API_KEY or ANTHROPIC_AUTH_TOKEN is exported in your environment, Claude Code may route through API billing instead of your Claude subscription. MeerKatta’s setup sheet checks for API credentials and flags them when detected; verify with claude auth status.
  • Cloud processing still applies: Calling a locally installed CLI does not make AI cleanup offline. Your transcript and relevant cleanup context (such as active app name, vocabulary, writing preferences, or prior text when applicable) still go to Anthropic or OpenAI under your existing account terms and data policy.
  • Mac-only for CLI polishing: Local CLI tools run on macOS, so Codex CLI and Claude Code cleanup are Mac-only features. One eligible purchase unlocks MeerKatta on iPhone, iPad, and Apple Watch too, where mobile devices use managed AI or supported cloud API keys.
  • Not a universal guarantee for every tier: Plan eligibility, rate limits, and CLI authentication rules are controlled by Anthropic and OpenAI and can change over time. Always verify with the built-in Test button during your 7-day Mac trial before buying Lifetime.

Frequently asked questions

Does MeerKatta store my Claude or ChatGPT login credentials?

No. CLI authentication stays entirely inside Claude Code or Codex CLI. MeerKatta only probes auth status during setup and invokes the local CLI binary—it never stores or displays your raw credentials or OAuth tokens.

Will Claude Code or Codex CLI run coding tasks or save dictation sessions to disk?

MeerKatta invokes both CLIs from macOS’s temporary working directory solely for text cleanup, with session-file persistence turned off so dictations don’t pile up as saved sessions on disk. On Claude Code, built-in tools (--tools ""), MCP servers, and slash commands are explicitly disabled (the background process stays warm in memory across dictations until shutdown or restart). On Codex CLI, MeerKatta runs non-interactive codex exec with --sandbox read-only, --ephemeral, --ask-for-approval never, and user configs and rules ignored.

Does CLI cleanup count against my subscription limits?

Yes. Dictation cleanup through Claude Code or Codex CLI uses your existing provider plan’s allowance and remains subject to Anthropic’s or OpenAI’s current terms and limits. It is not separate free or unlimited inference.

Do I still need a separate transcription provider?

Yes. Speech-to-text and text cleanup are separate stages. On Mac, you can pair CLI cleanup with built-in offline Apple Speech or On-device Whisper (no extra API keys), or with a cloud speech API like Groq, OpenRouter, or DeepInfra for higher raw accuracy.

Does CLI cleanup work on iPhone, iPad, or Apple Watch?

No. CLI cleanup depends on local macOS CLI binaries, so it is available on Mac only. An eligible purchase still unlocks MeerKatta across your Apple devices, where iPhone, iPad, and Apple Watch use managed AI or supported cloud API keys.
