BYOK vs. Managed AI

Bring Your Own API Key for AI Dictation: Is BYOK Worth It?

An API key gives you more choice and avoids another recurring software subscription. It also gives you one more account to set up and manage.

The short answer

Choose the responsibility, not just the label.

Pick BYOK (MeerKatta Lifetime, $33 launch / $49 regular) if you want a one-time license and already have a supported cloud API key—or want to use your existing Claude Code or Codex CLI subscription for the cleanup step on Mac instead of paying for another monthly dictation subscription.

Pick Managed AI (MeerKatta Subscription, $9.99/mo or $99.99/yr) if you want cloud transcription and AI polish to work immediately with zero provider setup, no API keys or CLIs to maintain, and one predictable bill.

Offline fallback on both plans: Mac includes two built-in on-device transcription providers—Apple Speech and On-device Whisper. Their accuracy isn't as high as a large cloud model, so cloud transcription is still stronger when you're online, but built-in offline transcription lets you keep dictating without network access (such as on an airplane).

Neither plan is more serious or more technical. Both include the same core capture and dictation workflows.

Most AI dictation apps lock you into a monthly subscription whether or not you already pay for AI services elsewhere. If you already manage an API key for work or personal projects, paying a second recurring markup just to clean up spoken drafts can feel unnecessary. On the other hand, if you simply want to hold a hotkey, speak an email, and move on with your day, creating a developer account and checking token bills can feel like work before the work.

How BYOK dictation works: two separate jobs

In MeerKatta, turning speech into clear text happens in two distinct stages: Transcribing turns your voice into raw text, and Polishing removes filler, groups self-corrections, and formats the draft while keeping your intent. On Mac, Providers & Keys lets you mix and match the provider for each stage independently.

  1. 1. Speak

    MeerKatta captures and transcribes your voice.Choose a cloud transcription API for higher accuracy, or switch to built-in offline Apple Speech or On-device Whisper when you have no network.

  2. 2. Clean up

    Your chosen polishing provider cleans and structures the text.Use a cloud API key (such as Groq, OpenRouter, or Cerebras) or run cleanup through your installed Codex CLI or Claude Code subscription on Mac.

  3. 3. Review

    Editable text lands at your cursor or in your Library.Check names, dates, numbers, and commitments before sending or saving.

Two built-in offline transcribers, explained honestly. Built-in Apple Speech and On-device Whisper (Whisper Small) run locally without network access. On-device transcription is not as accurate as a large cloud transcription model, especially with unusual names or noisy rooms, so cloud transcription + AI polish remains the stronger everyday option when you are online. Having both built-in offline providers means your dictation workflow still works on an airplane or anywhere with unreliable signal.

Reuse Claude Code or Codex CLI for cleanup. Most BYOK dictation tools only accept raw developer API keys. On Mac, MeerKatta Lifetime can automatically detect installed Codex CLI and Claude Code tools in the Polishing panel, letting developers who already pay for an eligible coding-tool subscription use that setup for text cleanup rather than managing a separate polishing API bill. Detection only identifies the installed CLI—you still need an authenticated, eligible subscription, and provider usage limits and terms still apply.

Real cost split: $33 one-time license vs. managed subscription

Keep software cost and AI usage cost separate. A one-time BYOK license buys access to the MeerKatta app; it does not include free or unlimited inference from third-party providers. Your provider bills you separately for the API calls your dictation uses (subject to that provider's current pricing and limits).

Privacy reality: why your own API key is not offline mode

Bringing your own key is not a blanket privacy guarantee. When you connect a personal API key to a cloud AI service, your dictation request still travels over the network to that cloud provider. You are responsible for reviewing that provider's data retention terms, securing your key, and following your organization's rules for work material.

What BYOK does change is the path and control:

  • Direct to your chosen provider: audio and text for cloud processing go to the supported provider you configure rather than through MeerKatta's managed AI proxy.
  • Local library by default: your saved captures live in your device library, with optional iCloud sync if you turn it on. See the Privacy Policy for exact storage and handling details.
  • True offline fallback is separate: when you are on a plane, away from signal, or capturing rough words without cloud polish, basic raw transcription can work without cloud AI.

Who should pick BYOK — and who should skip it

Choose BYOK Lifetime ($33) if…

  • You already maintain an account with a supported AI provider or get API keys through work.
  • You prefer paying once for Mac software instead of stacking another $10/month subscription.
  • You want direct control over your provider account and usage limits.
  • You already run an eligible Codex or Claude Code CLI on Mac for daily work.

Choose Managed Subscription if…

  • You want dictation and cleanup working in two minutes without creating developer accounts.
  • You do not want to track separate API invoices, keys, or rate limits.
  • You care more about building a daily capture habit than configuring the AI stack.
  • You prefer a single predictable monthly ($9.99) or yearly ($99.99) plan you can cancel anytime.

Check supported providers inside the app first. Rather than promising every LLM on the market, MeerKatta focuses on reliable supported setups shown directly inside Mac provider settings. Start with the trial, inspect the available providers, and see current plan details before buying.

Platform note: the provider-settings description above applies to Mac. On iPhone, iPad, and Apple Watch, the App Store shows local pricing, one-time MeerKatta + Your AI or subscription options, and trial eligibility before purchase.

Frequently asked questions

Does the $33 MeerKatta Lifetime license include AI API usage?

No. The one-time Lifetime license ($33 launch price, normally $49) covers the MeerKatta software. When you connect your own API key, provider usage charges are billed separately by your AI provider under your account.

Which AI providers work with MeerKatta BYOK?

On Mac, Providers & Keys separates Transcribing (built-in offline Apple Speech and On-device Whisper, plus cloud APIs such as Groq and OpenRouter) from Polishing (Codex CLI, Claude Code, OpenRouter, Groq, and Cerebras). Supported providers can evolve over time and are always shown directly inside the app; CLI cleanup requires an authenticated, eligible subscription with that provider.

Is bring-your-own-key dictation completely offline?

No. Connecting your own API key or CLI to a cloud service still uses cloud processing under that provider's data policy. Separate from cloud AI polish, MeerKatta on Mac includes two built-in offline transcription providers—Apple Speech and On-device Whisper—so you can keep dictating without network access, such as on an airplane.

Can I try MeerKatta before deciding between BYOK and Subscription?

Yes. On Mac, MeerKatta includes a 7-day free trial with no credit card required. Try speaking a real email or rough thought first, then pick Lifetime or Subscription on the pricing page. On iPhone and iPad, Apple displays local pricing and trial eligibility on the App Store.

Does one purchase unlock MeerKatta across Mac, iPhone, iPad, and Apple Watch?

Yes. Sign in and an eligible purchase made on Mac or in the App Store unlocks MeerKatta on your other devices too. Store billing, cancellation, and refund rules follow the platform where you bought (see Terms and Refund Policy).
